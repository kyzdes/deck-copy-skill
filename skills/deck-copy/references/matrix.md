# MATRIX — консолидированная матрица приёмов движка текстов

> Свод всех правил шести школ + методики v1 в одну таблицу приёмов, сгруппированную по темам. Каждый приём дедуплицирован (одно правило под разными именами = одна строка с синонимами). У каждого приёма помечен ЖАНР — ключевое разграничение всего движка: **[сцена]** произносимая дека · **[док]** читаемая дека-документ (leave-behind) · **[питч]** убеждение (инвест-дек / продуктовый лонч) · **[любой]** все жанры · **гибрид** — арка секций [сцена] + дата-слайды [док].
>
> Метаправило, вытекающее из всех шести дайджестов: **почти всё, что усиливает слайд на бумаге, перегружает его на сцене, и наоборот.** Поэтому спор двух школ почти всегда разрешается не «кто прав», а «какой жанр».

- **№1–3, 13** — уже есть в v1 (правила 1, 2, 3), наука их только подтверждает и уточняет пороги (RU-длина, ≤2 строк).
